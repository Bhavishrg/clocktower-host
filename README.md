# Ravenswood Bluff

A mobile-friendly Storyteller companion for in-person **Blood on the Clocktower** games. The host manages a private Grimoire, prepares the cast, and passes one phone around when players need to see character tokens.

The guided flow covers player names and seating, role assignments, setup choices, character distribution, and the first night. Players select their own names during distribution, reveal their character privately, then hide it before passing the phone. The Storyteller uses a PIN to return to the Grimoire.

During play, the roundtable tracks roles, deaths, votes, and reminders such as poison and the Fortune Teller red herring. The night order follows the characters in play. The host records choices and information given, shows character tokens when needed, and can review the game log. Rosters can be imported from Excel or CSV, and games can be backed up and restored as JSON.

This GitHub Pages edition runs entirely in one browser. It does not synchronize devices or connect players to a server. Game data is saved locally in that browser; the PIN covers the screen during handoffs but does not encrypt storage. The Storyteller remains responsible for rulings and outcomes.

An unofficial fan-made tool; not affiliated with The Pandemonium Institute.
